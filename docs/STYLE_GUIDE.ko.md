# 한국어 번역 문체 지침

## 기본 원칙

- 자연스러운 한국어를 우선하되 게임 정보와 변수는 정확하게 보존합니다.
- 화면 폭이 좁은 UI는 의미를 유지하는 범위에서 간결하게 번역합니다.
- 원문에 없는 사실을 추가하거나 허구 설정을 실제 사실로 교정하지 않습니다.
- 의도된 말장난은 직역보다 게임 진행에 필요한 힌트 전달을 우선할 수 있습니다.

## 화면별 문체

- 도감과 설명문: ~다 문체
- 담당자 대사: 친근한 반말
- 손님 대사: 캐릭터별 개성과 기존 말투 유지
- 설정·버튼·알림: 짧은 명사형 또는 자연스러운 동작 표현
- 튜토리얼: 사용자가 바로 행동할 수 있는 명확한 지시문

## 형식 보존

- {LevelName}, {0}, {""} 등 중괄호 표현은 그대로 유지합니다.
- 줄바꿈을 임의로 늘리지 말고 인게임 레이아웃을 확인합니다.
- 숫자와 단위는 의미를 확인한 뒤 한국어 표기 관례에 맞춥니다.
- 고유명사 대소문자와 의도된 특수기호를 보존합니다.

## 검수할 화면

- 제목 화면과 설정
- 설정 초기화 확인 문구
- 튜토리얼과 선택 버튼
- 도감의 긴 설명
- 상점과 손님 대사
- 미끼 힌트
- 지역 선택
- 서로 다른 해상도에서의 줄바꿈과 잘림
